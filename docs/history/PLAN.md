# План исправлений GGskript v2

Источник: `/workspace/ggskript/REVIEW.md`. Работа ведётся в `/workspace/ggskript/v2`, оригинал на ПК не трогается.
Порядок выполнения строгий: следующий пункт начинается, только когда тесты текущего пройдены на 100 %.
Тесты: Pester 5.9.1 на PowerShell 7.4 (Linux-бокс) + синтаксис/Pester на Windows PowerShell 5.1 на ПК (только тесты без побочных эффектов, в папке GGskript_v2).
Всё, что зависит от живых окон (UIA, user32, буфер, фокус, реальный Gemini/Antigravity/Telegram), вынесено за адаптеры; в юнит-тестах — моки; на живых окнах — «требует ручной проверки» с чек-листом (см. REPORT.md, раздел 4).

Уточнения по факту чтения лаунчеров на ПК (только чтение): `GGskript.bat` уже использует `%~dp0`, а `GGskript_cmd.bat` уже проверяет пустой ввод (`if not defined CMD`) — эти два замечания ревью не подтвердились. Подтвердились: UTF‑8 **BOM** в `GGskript_cmd.bat`, `GGskript_pause.bat`, `GGskript_start.bat` (ломает первую строку `@echo off`) и небезопасный `echo %CMD%` (спецсимволы `& | < > ^`).
